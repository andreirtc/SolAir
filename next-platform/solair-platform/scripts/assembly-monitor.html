SOLAIR · Assembly USB reader

Bench checks support firmware 2.0.19 and 2.0.20. Standalone arming requires the prepared 2.0.20 build. Close Arduino Serial Monitor and the app’s USB connection, open this file in desktop Chrome/Edge, then connect the ESP32. No account or internet needed.

Disconnected — readings are not live

Read from top to bottom. “ok” is the firmware’s reported status, not proof of accurate measurement. No commands run automatically. Arm bench sends an explicit ARM command after 10 seconds of device uptime with each enabled switch secure. Releasing a switch while armed can sound the connected siren. Disarm before disconnecting. Enable standalone arming explicitly saves an arm request for future boots; enabled secure contacts and the startup guard still apply. Disarm cancels this saved request. Pause LTE is an explicit bench command. This tool does not start LTE or forward USB data to a server.
