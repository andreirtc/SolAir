Follow these steps in order when CPE is available

If the battery-powered CPE keeps transmitting LTE, the server can still receive it. After a laptop restart, restore the server and both tunnel processes before testing.

With the meter in DCV 200, measure PZEM bottom VB+ against the VB− terminal immediately above it. Expect approximately the same voltage as protected battery + to DALY P− (previously 54.4 V). Do not select resistance on an energized circuit.
  7. Check PZEM communications power. If its battery input is present, measure the separate communication connector 5V to GND: approximately 5 V. MAX3485 logic VCC remains 3.3 V. With all sources isolated, check A→A, B→B and communication GND→MAX3485 GND. Correct supply with continued no-reply can indicate damage from the earlier spark; do not hide the fault in software.
