# SOLAIR

The current centralized SOLAIR application is **next-platform/solair-platform**. Older folders are preserved reference material.

The November 2026 source snapshot combines the updated frontend with the current backend, SOC/time-to-empty estimates, research evidence APIs, telemetry/GPS quality gates and opt-in LTE command support. See [combined integration](next-platform/solair-platform/docs/COMBINED_APP_INTEGRATION_2026-10-29.md) and [current validation](next-platform/solair-platform/docs/CPE_VALIDATION.md) for software checks and the remaining physical acceptance. Calibration, working databases, per-device secrets and private firmware settings are not supplied by a source checkout.
