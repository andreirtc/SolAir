## Storage, export and display metadata (not sender measurements)

SQLite persists each accepted canonical message in `message_json` (non-null TEXT). Projection columns: `schema_version` INTEGER <- `schemaVersion`; `source` TEXT <- `source`; `device_id` TEXT <- `deviceId`; `session_id` TEXT <- `sessionId`; `sequence` INTEGER <- `sequence`; nullable `sender_at_utc` TEXT <- `sampledAtUtc`. `id` is a non-null generated integer record ID; `received_at_utc` is non-null server UTC ISO TEXT. No calibration applies to these software metadata fields; physical interfaces are N/A and firmware agreement on their integration remains Unconfirmed, evidence Not supplied. Software lead owns storage/export behavior and verification.

CSV mapping: `record_id` <- id; `schema_version`, `source`, `device_id`, `session_id`, `sequence` <- their projection counterparts; `sender_time_utc` <- sampledAtUtc; `server_receipt_time_utc` <- received_at_utc. Measurements map respectively to `battery_voltage_V`, `battery_soc_percent`, `time_to_empty_seconds`, `solar_power_W`, `wind_power_W`, `latitude_deg`, `longitude_deg`, `gps_fix_valid`, `security_state`, `speed_km_h`, `electromagnetic_brake_active`. CSV has blank nulls, literal zero/false and protected text; it exports simulated records only.

Backend snapshot metadata: `backendId` startup UUID string; `message` payload or null; `receivedAt` server receipt in Unix epoch milliseconds or null; `count`/`storedCount` nonnegative lifetime stored counts; `sessionCount` nonnegative current-startup accepted count; `paused` boolean; `validationError`/`storageError` string or null. Receipt is captured for acceptance and exposed only after commit, never refreshed by SSE delivery. Database restart restores original receipt/count/latest message; startup controls/errors and current-startup count reset. These are software state, not device network state, device faults or experiments.

Frontend-only fixture fields: `source='demo'`, `locationLabel` string, `mqttConnected=false`, `gpsConnected=false`, and `initialSecurityState='ARMED'`; none is a wire measurement. Display freshness and SSE connectivity are derived locally, not firmware network reports. Fixed energy chart intervals are Wh examples; map imagery and alert history are examples outside the telemetry contract. No sensor/interface, calibration or hardware approval is established for these examples.

## Missing fields and evidence
